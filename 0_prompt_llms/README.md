# LLM Bias Analysis

This project investigates bias in Large Language Model (LLM) responses, particularly focusing on how OpenAI's LLM interpret and respond to politically sensitive prompts. The analysis compares reasoning processes, web search behaviors, and response patterns across different LLM configurations.
